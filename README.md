### 🏆 Proyectos Destacados (Experiencia Privada)

Dado que la mayor parte de mi trabajo reciente es propietario, aquí hay un resumen de los sistemas que he construido en producción:

- **Korekenke (Sistema de Asistencia del Ejército del Perú):** Módulo integral web y móvil construido con React Native y Expo. Implementé geofencing y validación biométrica (facial y dactilar).
